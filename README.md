# 随机相册壁纸 · 打包 / 安装 / 使用教程（Redmi K60E · HyperOS 2.0.25.0）

这是一个**原生安卓动态壁纸程序（APK）**，不是电脑程序、网页或小程序。
工程为纯 Android Framework API（Java，无 androidx、无第三方库），用 **GitHub Actions 在线编译**，
全程浏览器操作，**不需要安装 Android Studio，也不需要在电脑上装 Android SDK**。

---

## 一、这套代码怎么满足你的需求

| 需求 | 实现方式 |
| --- | --- |
| 直接选一整个相册文件夹，一次导入全部图片 | `ACTION_OPEN_DOCUMENT_TREE` 选目录 + `takePersistableUriPermission` 持久授权，遍历该目录下一层所有 `image/*` 文件 |
| 手动同步、不后台扫描 | 全工程**只有** `WallpaperPool.sync()` 会遍历相册，且只在「选择文件夹」和「点击手动同步」时被调用；没有 WorkManager / AlarmManager / JobScheduler / ContentObserver / 开机广播 |
| 新增加入、删除移除 | 每次同步把壁纸池全量镜像成"当前文件夹的图片集合"，用 documentId 做集合差集，得到新增/移除 |
| 随机切换，不按顺序 | `Random` 随机起点取图，且自动避开当前这张 |
| 60 秒 / 120 秒 | `RadioGroup` 两档，写入配置后广播通知壁纸服务重排 `Handler` 定时器 |
| 双击壁纸切换 | `Engine.onCreate` 里 `setTouchEventsEnabled(true)` + `GestureDetector.onDoubleTap` |
| 息屏→亮屏解锁换图 | 动态注册 `ACTION_SCREEN_OFF / SCREEN_ON / USER_PRESENT`，解锁时随机换一张新图（含无锁屏机型的兜底判断） |
| 界面简洁 | 只有 3 张功能卡片 + 「设为动态壁纸」「后台保活设置」两个**必要入口**（第三方 APP 无法静默设置壁纸，必须有一个跳转按钮） |
| HyperOS 保活 | `BIND_WALLPAPER` 由系统壁纸管理器长期绑定；服务被回收后系统自动重绑，从本地配置恢复壁纸池；灭屏停定时器省电；提供电池白名单与自启动引导 |

**两处设计说明（重要）：**

1. **选择文件夹时会自动导入一次。** 这是"你主动完成文件夹选择"这个动作触发的一次性导入（满足需求 1），
   此后**只有点【手动同步】才会再读相册**（满足需求 2）。整个过程没有任何后台扫描。
2. **只导入选中文件夹这一层的图片，不递归子文件夹。** 例如选 `Pictures/风景` 就导入 `风景` 里面直接放着的图片。
   如果图片放在 `风景/2026旅行/` 里，请直接选到 `2026旅行` 这一层。

## 二、在线打包成 APK（推荐：GitHub Actions，浏览器操作）

> 全程约 10 分钟。公开仓库的 Actions 免费且不限时长；构建本身约 3～8 分钟。
> 你只需要一个 GitHub 账号和一个浏览器（电脑浏览器最方便，手机浏览器也能做，就是粘贴代码麻烦）。

### 步骤 1：准备工程文件夹

把本目录 `RandomWallpaper/` 解压到一个好找的位置，确认里面有这些文件：

```
RandomWallpaper/
├── settings.gradle
├── build.gradle
├── README.md
├── .github/workflows/build.yml
└── app/
    ├── build.gradle
    └── src/main/
        ├── AndroidManifest.xml
        ├── java/com/example/randomwallpaper/
        │   ├── MainActivity.java
        │   ├── RandomWallpaperService.java
        │   ├── WallpaperPool.java
        │   ├── BitmapDecoder.java
        │   └── Prefs.java
        └── res/...（values / drawable / layout / xml）
```

### 步骤 2：新建 GitHub 仓库

1. 打开 <https://github.com> 并登录（没有账号先注册，免费）。
2. 右上角 **+** → **New repository**。
3. Repository name 填 `RandomWallpaper`，选 **Public**（公开仓库 Actions 免费）。
4. **不要**勾选 "Add a README file"、不要选 .gitignore、不要选 license。
5. 点 **Create repository**。

### 步骤 3：上传工程文件（除 `.github` 外）

1. 在仓库首页点 **Add file** → **Upload files**。
2. 把 `RandomWallpaper` 文件夹里的内容拖进上传区：
   `settings.gradle`、`build.gradle`、`README.md`、`app/` 整个文件夹。
   > 网页上传文件夹会保留目录结构，看到 `app/src/main/...` 这样的路径就对了。
   > 文件较多时可以分 2～3 次上传，每次都点 **Commit changes**。
3. ⚠️ **先不要管 `.github` 文件夹**——它是隐藏目录，浏览器拖拽上传通常会直接跳过它，下一步单独创建。

### 步骤 4：单独创建编译流水线（关键一步，别漏）

1. 仓库首页点 **Add file** → **Create new file**。
2. 在文件名输入框里**完整输入**（包含点和斜杠）：
   ```
   .github/workflows/build.yml
   ```
   GitHub 会自动创建 `.github/workflows/` 两级目录。
3. 把工程里 `.github/workflows/build.yml` 的内容**原样粘贴**进去。
4. 点 **Commit changes**。

> 如果这一步没做，仓库里没有 workflow，Actions 页面就是空的，不会编译出 APK。

### 步骤 5：触发构建

- 上一步的提交本身就是一次 `push`，通常已经自动开始构建。
- 也可以手动触发：顶部 **Actions** → 左侧 **Build APK** → 右侧 **Run workflow** → 再点一次 **Run workflow**。

### 步骤 6：等构建完成并下载 APK

1. 刷新 Actions 页，看到黄色圆点=正在跑，绿色对勾=成功，红色叉=失败。
2. 点进这次运行记录，拉到页面最底部 **Artifacts** 区域。
3. 点 **RandomWallpaper-debug-apk** 下载（是一个 zip）。
4. 解压 zip，得到 **`app-debug.apk`**（约 1～2 MB，已带 debug 签名，可直接安装）。

> 构建失败常见原因见文末「常见问题」。绝大多数是 workflow 文件放错位置或没粘贴完整，重跑一次即可。

### 备选打包方案（都不需要 Android Studio）

- **GitHub 网页反复改**：以后想改代码，直接在仓库里点文件 → 铅笔图标编辑 → Commit，会再自动编译一次，非常方便。
- **本地轻量命令行**（有电脑、愿意装小工具时）：装 JDK 17 + Android SDK commandline-tools（合计几百 MB，远小于 Android Studio 的数 GB），
  在工程目录执行 `gradle assembleDebug`，产物同样是 `app/build/outputs/apk/debug/app-debug.apk`。
- **不推荐**：App Inventor / Kodular / 在线"APK 生成器"不支持自定义 `WallpaperService`，
  做不出动态壁纸；手机端 AIDE 对该工程的多模块 Gradle 配置兼容性差，容易踩坑。

## 三、把 APK 装到 Redmi K60E

### 方式 A：传到手机安装（推荐）

1. 用数据线、QQ/微信发给自己、网盘或邮件，把 `app-debug.apk` 放到手机上。
2. 在手机 **文件管理** 里找到这个 APK 并点击（**不要**在聊天窗口里直接点"用其他应用打开"）。
3. 若提示"禁止安装未知来源应用"：按提示给「文件管理」开启 **安装未知应用** 权限。
4. 若 **纯净模式** 拦截：点「仍要安装 / 已知风险继续安装」；或者先去
   `设置 → 应用设置 → 纯净模式` 临时关闭。
5. 若弹出"安装包验证 / 病毒扫描"，选择"继续安装"（debug 自签名包属正常）。
6. 安装完成，桌面出现 **随机相册壁纸**。

### 方式 B：adb 安装（可选，电脑上只装 ~10MB 的 Platform-Tools）

1. 手机：`设置 → 我的设备 → 全部参数与信息` 连点「OS 版本」7 次开启开发者选项；
   `设置 → 更多设置 → 开发者选项` 打开 **USB 调试**（小米部分版本还需要登录小米账号）。
2. 电脑下载 Android SDK Platform-Tools 并解压，在解压目录打开命令行。
3. 数据线连接手机，手机上点「允许 USB 调试」，然后执行：
   ```
   adb devices
   adb install -r "C:\路径\app-debug.apk"
   ```
   看到 `Success` 即安装成功。

## 四、安装后首次配置（按顺序做）

1. 打开 **随机相册壁纸** → 允许弹出的**照片权限**。
   > 即使拒绝了也不影响主流程：本 APP 读图片靠的是下一步的「文件夹授权」。
2. 点 **选择相册文件夹** → 在系统文件选择器里选到目标分类相册（如 `Pictures/风景`）→ 点「使用此文件夹」。
   > 界面会显示"已选择：风景"，并自动同步一次，提示"新增 N 张"。
3. 点 **手动同步** 复核一次（可选），确认「壁纸池：N 张」。
4. 选择 **60 秒** 或 **120 秒**。
5. 点 **设为动态壁纸** → 在系统壁纸页选择「随机相册壁纸」→ 点「应用 / 设置壁纸」。
   > HyperOS 可能忽略自动跳转，此时手动进 `设置 → 壁纸与个性化 → 壁纸 → 动态壁纸` 找到它。
   > 如果壁纸页让你选作用范围，按需要选「桌面」或「桌面和锁屏」。
6. 点 **后台保活 / 权限设置** → 在弹窗里选「允许」加入电池优化白名单；
   再按下面第五节的清单，把自启动、省电策略逐项设好。

### 功能自检清单

| 检查项 | 预期结果 |
| --- | --- |
| 往文件夹里放 1 张新图、删 1 张旧图，点【手动同步】 | 提示"新增 1 张，移除 1 张"，池数量相应变化 |
| 不做任何操作，过 10 分钟回来看 | 壁纸池数量不变（APP 没有后台扫描） |
| 等 60 / 120 秒 | 随机换一张，且不会连续两次同一张 |
| 在桌面**空白区域**快速双击 | 立刻换一张 |
| 按电源键息屏 → 再亮屏解锁 | 自动换成一张新图 |
| 重启手机 | 壁纸一般会自动恢复；若变回静态壁纸，重新执行一次第 5 步 |

## 五、⚠️ HyperOS / 红米机型专属坑（单独清单）

### A. 安装后必须在系统设置里**手动开启**的权限

| 项目 | 路径（HyperOS 2 大致位置，不同小版本名字略有差异） |
| --- | --- |
| 照片和视频权限 | `设置 → 应用设置 → 应用管理 → 随机相册壁纸 → 权限管理 → 照片和视频 → 允许` |
| **文件夹目录授权**（最关键） | 只能在 APP 内点「选择相册文件夹」，由系统文件选择器授予；不能在设置里手动开 |
| 自启动 | `设置 → 应用设置 → 授权管理 → 自启动管理 → 找到本 APP → 允许` |
| 安装未知应用（仅安装阶段） | `设置 → 应用设置 → 授权管理 → 安装未知应用 → 文件管理 → 允许` |
| 「设置壁纸」 | 系统不允许第三方静默设置，必须在壁纸页手动点选（APP 内按钮只是跳转） |

### B. 必须**关闭 / 放行**的省电与后台限制（不做这一步最容易"壁纸停止切换"）

| 要关的东西 | 路径 |
| --- | --- |
| 电池优化（加入白名单） | APP 内点「后台保活 / 权限设置」→ 弹窗选「允许」；或 `设置 → 省电与电池 → 更多设置 → 电池优化 → 找到本 APP → 不优化` |
| 应用省电策略 | `设置 → 应用设置 → 应用管理 → 随机相册壁纸 → 省电策略 → 无限制`（**不要**选"智能限制后台运行"） |
| 睡眠待机优化 | `设置 → 省电与电池 → 更多设置 → 睡眠待机优化 → 关闭` |
| 省电模式 / 超级省电 | 下拉控制中心关掉；低电量自动开启省电模式时会明显影响后台 |
| 手机管家内存加速白名单 | `安全中心/手机管家 → 垃圾清理/内存加速 → 设置 → 受保护应用/白名单 → 加入本 APP`；不要一键清理后立刻检查壁纸 |
| 后台运行限制 | `设置 → 应用设置 → 应用管理 → 本 APP → 后台运行管理 → 允许后台运行` |

> 原理：`WallpaperService` 由系统壁纸管理器通过 `BIND_WALLPAPER` 长期绑定，优先级高于普通后台服务，
> 但 HyperOS 的"睡眠待机优化 / 神隐模式 / 一键清理"仍可能连带回收它。服务被回收后系统一般会自动重绑并从本地配置恢复，
> 但若开着严格省电策略，可能出现"亮屏解锁不换图 / 定时切换卡住"，按上表全部放行即可解决。

### C. 双击功能在 HyperOS 上的真实限制（按你的要求不强行绕过）

- 动态壁纸默认收不到触摸事件，代码里已 `setTouchEventsEnabled(true)` 打开；但**事件能否传到壁纸，取决于系统桌面**。
- **图标、小组件、文件夹、Dock 栏区域**：桌面会自己消费点击，壁纸收不到，双击无效。请在**真正的空白处**双击。
- **桌面双击手势会抢事件**：`桌面长按/双指捏合 → 桌面设置 → 更多设置 → 手势`，关掉"双击锁屏 / 双击呼出"之类的双击动作。
- HyperOS 桌面在「标准模式 / 抽屉模式」下分发逻辑不同，换一种模式可能就好了。
- 如果以上都试过仍无效，就是系统桌面的硬性拦截，**按你的要求保留现状、不强行实现**；
  此时仍可用「定时切换」「亮屏解锁切换」「APP 内手动同步」来换图。
- 长按壁纸弹出的桌面菜单是系统行为，不属于本 APP 功能。

### D. 相册 / 文件夹相关坑

- **"风景""人物"这类智能分类相册往往不是真实磁盘目录**，而是相册 APP 的虚拟分组：
  在 SAF 文件选择器里可能看不到，或选完后返回 0 张，甚至重启后授权失效。
  **最稳做法**：在「文件管理」里新建真实文件夹（例如 `Pictures/风景`），把图片放进去，然后选这个真实目录。
- **持久目录授权会失效**：HyperOS 清理授权、重启、卸载重装文件管理器后，`takePersistableUriPermission` 的授权可能丢失，
  表现为同步时报「无法读取该文件夹」。APP 界面会提示"目录授权可能已失效"，**重新选一次文件夹即可**（壁纸池会自动重建）。
- **只扫描选中目录这一层**，不递归子文件夹（见第一节说明）。
- 云相册、私密相册、SD 卡部分路径，SAF 可能读不到或需要对应厂商的 DocumentsProvider。
- 单张超大图（4000×3000 以上）已做降采样，不会 OOM；HEIC/HEIF 用 `ImageDecoder` 解码；
  损坏或无法解码的图片会在本次运行内跳过，不会导致壁纸卡死。

### E. 其它

- 系统重启后 HyperOS 偶尔会回退到静态壁纸，属于 ROM 行为，重新设一次动态壁纸即可。
- 息屏期间**故意不切图**（省电、降低被杀概率），亮屏解锁时才换，这是需求 6 的实现方式。
- 本 APP 不含任何联网代码、统计、广告、后台任务，也不会上传你的照片。

## 六、常见问题排查

| 现象 | 处理 |
| --- | --- |
| Actions 页面空白 / 没有 Build APK | `.github/workflows/build.yml` 没建成功，回到步骤 4 用「Create new file + 输入完整路径」重做 |
| 构建红叉：`SDK location not found` | workflow 里 `写入 SDK 路径` 那步被删了，确认有 `echo "sdk.dir=$SDK_PATH" > local.properties` |
| 构建红叉：找不到 AGP / 依赖下载失败 | 确认 `settings.gradle` 里 `pluginManagement` 有 `google()`；网络波动时点 **Re-run all jobs** 重跑 |
| 编译报 `READ_MEDIA_VISUAL_USER_SELECTED` 不存在 | 确认 `app/build.gradle` 里 `compileSdk 34` 没被改小 |
| 手机提示「解析包错误 / 应用未安装」 | APK 没下载完整（要从 Artifacts 的 zip 里**解压**出来用）；或系统版本低于 Android 8.0（K60E 不会） |
| 被「纯净模式」拦住 | 安装时点「仍要安装」，或临时关闭纯净模式 |
| 动态壁纸列表里找不到本 APP | 确认 `AndroidManifest.xml` 里 service 的 `BIND_WALLPAPER` 声明还在；重装 APK 并重启一次；在壁纸页切到「动态壁纸」分类 |
| 选完文件夹显示 0 张 | 选到了虚拟分类相册或空目录；换成「文件管理」里的真实文件夹，且图片要直接放在该层 |
| 同步提示「无法读取该文件夹」 | 目录授权失效，重新点「选择相册文件夹」选一次 |
| 定时切换偶尔停 | 按第五节 B 表把省电策略全部放行；确认没有开省电模式 / 睡眠待机优化 |
| 双击没反应 | 按第五节 C 表逐项排查；确属桌面拦截则属系统限制 |

## 七、代码结构

| 文件 | 作用 |
| --- | --- |
| `MainActivity.java` | 界面、权限申请、文件夹选择、手动同步、间隔设置、壁纸/保活跳转 |
| `WallpaperPool.java` | 唯一扫描相册的地方；增量同步、壁纸池存取、URI 还原 |
| `RandomWallpaperService.java` | 动态壁纸服务：随机切换、定时、双击、亮屏解锁、绘制、广播 |
| `BitmapDecoder.java` | 按屏幕尺寸降采样解码，兼容 HEIC/WebP，避免大图 OOM |
| `Prefs.java` | SharedPreferences 配置（目录 URI、壁纸池、间隔、上次同步） |
| `res/xml/wallpaper.xml` | 动态壁纸元数据（缩略图、描述、设置入口） |
| `.github/workflows/build.yml` | 在线编译流水线 |
